# ResusBay

An interactive visual guide to equipment and storage locations within the Emergency Department resuscitation area.

## Overview

ResusBay provides a clickable image map of the resuscitation bay, allowing users to quickly access equipment checklists and location-specific information by selecting items directly from a photograph.

The aim is to improve familiarity with equipment locations and provide rapid access to relevant checklists and reference material.

## Features

* Interactive resuscitation bay photograph
* Mobile-friendly interface
* Clickable equipment hotspots
* Direct links to checklist forms
* Visual highlighting of selected equipment areas
* No login required

## Current Equipment Areas

The following equipment locations are currently linked:

* Entire Bay Overview
* Airway & Breathing Trolley
* Circulation & Monitoring Trolley
* Panda Trolley
* Sideboard Equipment
* HALO Trolley
* Access Trolley
